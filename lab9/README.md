# Лаб 9. Зургийн цомог порталын санал хүсэлтийн form-д JavaScript validation бичих

## 1. Даалгавар 1: Хувьсагч, төрөл, хөрвүүлэлтийн туршилт (`js/types-experiment.js`)
Хуудсыг нээх үед хөтчийн консол руу (`F12 -> Console`):
- `typeof` оператороор бүх төрлүүдийг (`undefined`, `number`, `bigint`, `string`, `boolean`, `symbol`, `null`, `object`, `function`) шалгасан хүснэгт.
- Ил (Explicit) ба Далд (Implicit coercion) хөрвүүлэлтүүд (`Number()`, `String()`, `Boolean()`, `"5" + 2`, `"5" - 2`, `true + 1`, `null == undefined`, `null === undefined` г.м).
- `0.1 + 0.2` үйлдлийн хоёртын бутархайн нарийвчлалын алдаа (`0.30000000000000004 !== 0.3`) болон `Number.EPSILON`, `toFixed(2)`, бүхэл тоогоор бодох шийдлүүдийг **`console.table()`** ашиглан хүснэгт хэлбэрээр хэвлэнэ.
- Вэб хуудас дээрх **«Туршилтын үр дүнг хуудсан дээр харах»** товчийг дарж хүснэгтүүдийг шууд үзэх боломжтой.

## 2. Даалгавар 2: Бэлэн функц ашиглаагүй 8 алгоритм (`js/algorithms.js`)
Эдгээр функцууд нь ямар нэгэн бэлэн shortcut (`Math.max`, `split().reverse().join()`, `match()`, `reduce()` г.м) ашиглахгүйгээр цэвэр математик болон давталт (`for`, `while`), хоёр заагч (`two-pointers`) аргаар бичигдсэн:

1. `sumTo(n)` — 1-ээс n хүртэлх тооны нийлбэр (for давталтаар).
2. `factorial(n)` — $n!$ тооцоолох (0! = 1, for давталтаар).
3. `isPrime(n)` — Анхны тоо эсэхийг $6k \pm 1$ алхамтай $i \times i \le n$ хүртэл шалгана.
4. `fizzBuzz(n)` — 1-ээс n хүртэл 3-т "Fizz", 5-д "Buzz", 15-д "FizzBuzz" бүхий массив үүсгэнэ.
5. `countVowels(str)` — Англи болон Монгол кирилл бүх эгшгүүдийг давхар давталтаар тоолно.
6. `isPalindrome(str)` — Хоёр захаас нь (`left`, `right`) тэмдэгт бүрээр харьцуулан зайг алгасаж шалгана.
7. `maxOf(arr)` — Массив эсвэл параметрүүдийн хамгийн их утгыг харьцуулан олно.
8. `digitSum(n)` — 10-т хуваах үлдэгдлээр (`num % 10`) цифрүүдийн нийлбэрийг олно.

## 3. Даалгавар 3: Form шалгах 4 функц (`js/validators.js`)

| Функц | Дүрэм |
|---|---|
| `validateName(value)` | Хоёр захын зайг хасна (`trim()`). Хоосон биш, 2–50 тэмдэгт, тоо агуулахгүй. |
| `validateEmail(value)` | Хоосон биш; «нэр@домэйн.өргөтгөл» хэлбэр (regular expression); зай агуулахгүй. |
| `validatePassword(value)` | Дор хаяж 8 тэмдэгт; хоосон зайгүй; үсэг (кирилл эсвэл латин) ба тоо агуулна. |
| `validateMessage(value)` | Хоёр захын зайг хасна (`trim()`). 10–500 тэмдэгт. |

Мөн хэрэглэгчид ээлтэй монгол тайлбар өгөх `getValidationError(field, value)` туслах функц хамт ажиллана.

## 4. Даалгавар 4: Form-той холбосон байдал (`js/form-handler.js`)
- Санал хүсэлтийн маягт (`#feedback-form`):
  - `input` эвент: Хэрэглэгч шивэх үед бодит цагт шалгаж, зурвасын тэмдэгтийн тоог харуулна (`10-500`).
  - `blur` эвент: Талбараас гарах үед алдааг тэр даруй улаанаар хүрээлж тайлбар өгнө.
  - `submit` эвент: Бүх 4 талбарыг баталгаажуулж, алдаатай бол эхний талбар руу фокуслана. Бүх утга зөв бол `console.table()`-д өгөгдлийг бүртгэж, ногоон амжилтын мэдэгдэл харуулна.
  - Нууц үг харах/нуух товч (`btn-toggle-pass`).
  - Хандах боломж (Accessibility): `aria-invalid`, `aria-describedby`, `aria-live="polite"`.
